# 03: Select and textarea answers end to end

**What to build:** Select fields present exactly the options declared in the template, start blank, and reject values outside the list. Textarea fields accept multi-line answers, and newlines become line breaks in the filled document.

**Blocked by:** 02.

**Status:** done

- [x] A select answer must be blank or one of its declared options.
- [x] Duplicate options collapse to the first occurrence.
- [x] Textareas render as multi-line inputs.
- [x] Newlines become `<w:br/>` line breaks in the same paragraph.
- [x] Select and textarea values substitute at every occurrence.
